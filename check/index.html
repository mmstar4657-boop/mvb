4. What the results mean

API failure (step 2 red): search itself failed. The message says why (key problem, daily limit used up, or our server unreachable). Videos can still embed; this is not the filter.

Not embeddable (player shows “owner does not allow”): the player loaded fine, but that one video's owner turned off embedding. Pick another video. Not the filter.

Likely filter block (step 1 “Player didn't load”): the YouTube player never answered at all within 15 seconds, or it loads but the video never starts after tapping play. On a filtered device that almost always means the filter is blocking one of the domains below. Ask GenTech to allow embedded YouTube for this site.
